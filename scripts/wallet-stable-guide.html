LOYALTY · DIRECCIÓN FIJA

Una dirección que puedas conservar.

Necesitas un dominio tuyo con DNS activo en Cloudflare. El asistente conecta el servidor local con el túnel que configures; no compra un dominio ni crea su DNS.

1. Crea el túnel en Cloudflare

  1. Abre Cloudflare y ve a Networking → Tunnels. Crea un túnel de tipo Cloudflared, por ejemplo loyalty-local.
  2. Copia solamente el token que comienza por eyJ... del comando de instalación. Para un túnel existente, puedes obtenerlo desde Add a replica. El instalador de Loyalty ejecutará el conector dentro de Docker.
  3. Añade una Published application route. Elige un subdominio propio, por ejemplo wallet, selecciona tu dominio y deja la ruta vacía.
  4. En el servicio de destino, elige HTTP y escribe loyalty-wallet-gateway:8080. Guarda la ruta.

Las rutas públicas de registro y Wallet deben llegar sin una pantalla de acceso de Cloudflare. El gateway mantiene fuera del túnel los paneles y las API de personal.

2. Conecta Loyalty desde el Mac

Ejecuta este comando en Terminal:

{{STABLE_COMMAND}}

Escribe la dirección HTTPS completa del subdominio y pega el token cuando se solicite. El token no se muestra al escribir, no va a Git ni al ZIP. Conserva tu clave y certificados de Wallet.

El proceso verifica HTTPS, la identidad del gateway y sus rutas. Solo un resultado HTTPS_PASS confirma esas comprobaciones; no confirma todavía la actualización del teléfono.

3. Guarda la conexión en la misma tarjeta

  1. Cuando pase HTTPS, abre el panel del negocio como dueño y busca al cliente en Caja.
  2. En Actualizar o recuperar esta tarjeta, elige La tarjeta no actualiza: reparar conexión, verifica al titular y crea el enlace temporal.
  3. Desde el iPhone, abre ese enlace, pulsa Recuperar mi tarjeta y Añadir a Apple Wallet. Confirma el guardado de la misma tarjeta.
  4. Registra una compra de prueba y comprueba el nuevo saldo en Wallet. Conserva el serial y los saldos existentes.

El dominio fijo evita perder la dirección por usar un enlace temporal. Mantén el Mac y Docker disponibles: no sustituye un servidor de producción encendido permanentemente.
